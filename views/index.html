ProgSumEval

ProgSumEval is a benchmark browser for evaluating AI-generated summaries of programming tutorial videos.

This website browses existing benchmark data, quiz questions, and evaluation results. It is not a live AI summarization tool, and it does not generate summaries automatically.

Browse Benchmark Review the 10 original programming tutorials and their summary videos. View Benchmark Results Compare quiz outcomes and quality ratings across summary engines. Submit Video Request Store a new tutorial request for offline review.
